# Document Classifier

## Опис
Electron застосунок для автоматичної класифікації документів.

## Функції
- Навчання моделі на текстах
- Класифікація документів
- Логування дій

## Виправлення (+fix)
- Додано перевірку порожніх файлів
- Додано перевірку назви файлу
- Покращена стабільність навчання моделі
